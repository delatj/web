Procedimiento 1: Instalación de un Sistema Operativo

Para instalar un Sistema Operativo en un equipo informático, se deben seguir los siguientes pasos clave:

  1. Descargar la imagen: Se obtiene la imagen de CD o archivo ISO oficial del sistema operativo.
  2. Crear medio de arranque: Con un programa especial (como Rufus o Ventoy), se carga la ISO en un pendrive USB.
  3. Configurar el arranque (Boot Menu): Se inserta el USB en el ordenador, se reinicia y se pulsa repetidamente una tecla como F9, F12 o F2 (según la marca de la placa base) para seleccionar el arranque desde el pendrive USB.
