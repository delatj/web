Resumen Teórico: Data Scraping (Criterio 4.3)

1. ¿Qué es Data Scraping?

Es la técnica automatizada para extraer información no estructurada alojada en páginas web y transformarla en datos estructurados.

2. Protocolo HTTP y Peticiones GET

Un scraper envía una petición con el método HTTP GET. Si la solicitud es exitosa, el servidor responde con el código 200 OK.

3. Identificación mediante User-Agent

La cabecera User-Agent identifica al cliente o programa ante el servidor web.

4. Modelo DOM y Selectores HTML

El DOM (Document Object Model) representa la web como un árbol de elementos HTML:

  • <h1>: Título principal de primer nivel.
  • <p>: Párrafo de texto.
  • <a> con atributo href: Enlace de hipertexto.
  • Selector #firstHeading en Wikipedia: Identifica el título principal.

5. Formatos de Salida (JSON y CSV)

Los datos extraídos se exportan en formatos estándar como JSON (pares clave-valor) o CSV (filas y columnas separadas por comas).

6. Ética y Archivo robots.txt

El archivo robots.txt ubicado en el servidor especifica las reglas de acceso y restricciones permitidas para los robots automáticos.
